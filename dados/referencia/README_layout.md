# Disposição das unidades da Federação

`layout_ufs.csv` foi extraído do objeto `br_states_grid1`, disponibilizado no repositório oficial do pacote geofacet, de Ryan Hafen e colaboradores:

- Fonte recuperada: https://raw.githubusercontent.com/hafen/geofacet/master/data/br_states_grid1.rda
- Repositório: https://github.com/hafen/geofacet
- Consulta: 16/10/2026.

O projeto utiliza somente a tabela de posições como referência; **não usa o pacote geofacet para desenhar**. O desenho será gerado pelas funções R do projeto.

Trata-se de um **cartograma esquemático**, não de uma malha cartográfica: posições relativas lembram o Brasil, mas distâncias e áreas não devem ser interpretadas geograficamente. Todas as 27 UFs têm o mesmo espaço para comparação, incluindo o Distrito Federal.
